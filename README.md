# Site Tamarozzi Embalagens

## Descrição do Projeto

Site da Tamarozzi Embalagens, com descrição da empresa, galeria de fotos, catálogo de produtos e informações do desenvolvedor. Desenvolvido como projeto acadêmico para o Bootcamp de Desenvolvimento Web Responsivo da Unisagrado 2026.

---

## Estrutura Inicial do Projeto

O projeto é composto por 4 páginas HTML e 1 arquivo CSS compartilhado:

- **index.html** - Página inicial com informações sobre a Tamarozzi Embalagens
- **galeria.html** - Galeria de fotos da empresa e eventos
- **produtos.html** - Catálogo de produtos com imagens e preços
- **desenvolvedor.html** - Informações sobre o desenvolvedor do site
- **index.css** - Arquivo de estilização único utilizado por todas as páginas

## Tecnologias Utilizadas

- **HTML5** - Estrutura e conteúdo das páginas
- **CSS3** - Estilização e responsividade
    - Flexbox para layouts
    - Media Queries para adaptação em tablet e mobile
    - Efeitos hover e transições

---

## Instruções para Instalação e Execução

1. No repositório do GitHub, clique no botão verde **Code**
2. Clique em **Download ZIP**
3. Extraia o arquivo ZIP em uma pasta do seu computador
4. Abra a pasta **MEU SITE FINALIZADO**
5. Abra o arquivo **index.html** no navegador (Chrome, Firefox ou Edge)
